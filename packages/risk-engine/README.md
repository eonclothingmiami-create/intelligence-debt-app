# @fie/risk-engine

Pure **Business Risk Score** for Business Financial OS.

Aggregates liquidity, break-even, debt coverage, margin, ads, inventory, and cash into a single 0–100 score with risk level.

## Weights

| Component     | Weight |
| ------------- | ------ |
| Liquidity     | 25%    |
| Break-even    | 20%    |
| Debt coverage | 15%    |
| Margin        | 15%    |
| Ads           | 10%    |
| Inventory     | 10%    |
| Cash          | 5%     |
