# @fie/optimization-engine

Pure **multi-objective optimization** for Business Financial OS.

Optimizes across liquidity, break-even safety, risk, ads ROI, and debt — **not** a debt-only avalanche/snowball picker.

## Role in the OS

| Consumer              | Uses this for                      |
| --------------------- | ---------------------------------- |
| recommendation-engine | Ranked action sets                 |
| simulation-engine     | Candidate generation               |
| Apps / API            | “Best next move” under constraints |
