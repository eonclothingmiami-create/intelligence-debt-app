# @fie/simulation-engine

Pure **cross-engine what-if center** for Business Financial OS.

Coordinates scenario patches across cash flow, break-even, liquidity, debt, and risk so consumers can compare outcomes without embedding orchestration in NestJS or React.

## Role in the OS

| Consumer              | Uses this for                     |
| --------------------- | --------------------------------- |
| recommendation-engine | Scenario comparison before advice |
| optimization-engine   | Candidate evaluation              |
| Apps / API            | Interactive what-if UI            |
