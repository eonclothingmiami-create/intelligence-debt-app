# @fie/break-even-engine

Pure **live break-even** model for Business Financial OS.

Independent of UI, NestJS, and databases. Any catalog change recalculates the whole business.

## Calibrated to

Local 311 spreadsheet (`PUNTO EQUILIBRIO`):

| Metric                     | Value                  |
| -------------------------- | ---------------------- |
| Variable cost / unit (sum) | COP 3.448              |
| Product cost               | COP 14.000             |
| Full unit cost             | COP 17.448             |
| Sale price (50% utility)   | COP 34.896             |
| Fixed costs                | COP 15.195.000         |
| BEP units                  | **870,87**             |
| BEP money                  | **COP 30.390.000**     |
| Daily (÷26)                | 33 uds / COP 1.168.846 |
