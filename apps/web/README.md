# @fie/web — Business Financial OS

Next.js App Router UI over the pure `@fie/*` engines.

## Run

From monorepo root:

```bash
npx pnpm@9.15.9 --filter @fie/web dev
```

- Landing: http://localhost:3000
- OS board: http://localhost:3000/app

## PWA

Install from mobile browser (HTTPS or localhost): menu → Install / Add to Home Screen.
